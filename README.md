#BookListView - 圖書瀏覽與借閱系統
這是一個使用 C# Windows Forms 研發的簡單圖書瀏覽與借閱管理系統。您可以透過不同的檢視模式（如大圖示、詳細資料等）輕鬆瀏覽書籍，並透過雙擊將想看的書籍加入右側的借閱清單中。

專案功能簡介
多功能檢視模式 (ListView)：支援 5 種不同的書籍檢視方式，包含大圖示、詳細資料、小圖示、清單以及大圖示加詳細資料（Tile）。

動態資料呈現：系統啟動時會自動載入預設的書籍資料（書名、作者、類別），並為每本書籍配置對應的封面圖示。

互動式借閱功能：

雙擊書籍時，系統會跳出確認對話框詢問是否借閱。

防重複借閱機制：系統會自動檢查，若該書籍已存在於「借書清單」中，則不會重複加入。

執行說明

開啟專案：使用 Visual Studio 開啟本專案的方案檔 (.sln)。

確認圖片資源（重要）：

本專案有使用 ImageIndex 來為書籍加上圖示。請確保你的 lvwBooks 控制項已在設計介面中綁定了 LargeImageList 與 SmallImageList，並依序放入與程式碼陣列（共 8 本書）長度相符的書籍封面圖片。

編譯並執行：按下 F5 或點擊 「開始」 按鈕執行程式。

操作方式：

切換檢視：點擊畫面上方的下拉選單（cmbView），即可切換清單的顯示樣式（例如切換到「詳細資料」可以看到作者與類別）。

借閱書籍：在想要借閱的書籍上連點滑鼠左鍵兩下（或按 Enter），在跳出的對話框中點選「是」，該書籍就會出現在右側的借閱清單（ListBox）中。
